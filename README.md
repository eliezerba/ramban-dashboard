# Ramban Dashboard V10.3 — Clean GitHub Release

זו חבילת פרסום נקייה של הדשבורד המלא בגרסה 10.2, ללא תיקוני דאטה או שינוי מחקרי. נשמרו כל הלשוניות, 9 התובנות המחקריות המלאות, 27 הדוחות הטכניים, הגרפים, מקורות הטקסט, הלוגו והדשבורד הישן.

## התקנה במאגר Git חדש

1. פתחו מאגר חדש וריק ב-GitHub (מומלץ לא להוסיף README או קובצי אתחול אוטומטיים).
2. חלצו את ה-ZIP והעלו את **תוכן** התיקייה, כך ש-`index.html` נמצא בשורש המאגר.
3. בהגדרות Pages בחרו `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`.
4. פתחו את האתר, בדקו שהלוגו מוצג, סעיף 21 נטען, דוחות תוכניים ודוחות טכניים פועלים, ושמעבר ל'דשבורד הישן' עובד.

אין להעלות למאגר את ה-ZIP עצמו. אין צורך בקומפילציה, התקנת תלויות או שרת.

## תכולה

- `index.html`, `app.js`, `app.css`: האתר.
- `assets/`: לוגו המעבדה.
- `data/`: מדדים, נתוני סעיפים, פרשנים, ותשע התובנות המשולבות.
- `source/stories/media/`: התמונות/התרשימים של תשעת הסיפורים.
- `source/new_reports/`: קובצי Markdown/PDF של ששת הדוחות הטכניים החדשים; שמות הקבצים הותאמו ל-ASCII, אבל הכותרות והתוכן נשמרו.
- `source/hadar_october_2026/`: דוח הדר וחבילת החוקרים להורדה. שמות קבצים עבריים הותאמו ל-ASCII בלי שינוי תוכן.
- `legacy/ramban-dashboard-V2/`: גרסת הדשבורד הישנה המקושרת מן האתר. נשמרו קוד, נתונים ונכסי תצוגה חיוניים בלבד.
- `V10_METHODS.md`, `V10_DATA_AUDIT.md`: מסמכי שיטה וסטטוס מחקרי נוכחיים.

## מה הוסר

ארכיוני ZIP ישנים, תיקיית `archive/`, קובצי QA היסטוריים, מסמכי changelog מגרסאות קודמות, קוד בנייה היסטורי, דוחות כפולים, קובצי DOCX שהסיפורים שלהם כבר מוטמעים, קובצי CSV ישנים כפולים ושמות קבצים פגומים (mojibake).

## הסתייגות מחקרית

`co-cluster` ההיסטורי של הדר נשמר כמקור ארכיוני בתוך הנתונים ולא מוצג כחישוב חדש. הסיפורים המחקריים עצמם הועברו במלואם לדשבורד, אך עדיין לא עברו עריכה פילולוגית מחדש. ראו `V10_METHODS.md` ו-`V10_DATA_AUDIT.md`.
